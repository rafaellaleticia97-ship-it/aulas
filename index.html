Parte 3

Sequência recursiva: a regra do "de um para o outro"

Na sequência não recursiva que revisamos, dava pra pular direto pro termo que quiséssemos, só substituindo n na fórmula T(n). Agora vem uma sequência diferente — nela, isso não vai funcionar.

Pense assim: "recursiva" é uma palavra grande para uma ideia simples. É como subir uma escada: para saber onde fica o próximo degrau, você só precisa saber onde está o degrau atual — não precisa lembrar de todos os degraus anteriores, mas também não tem como pular direto pro degrau 50 sem passar pelos outros. Em matemática, cada termo novo nasce a partir do termo anterior, seguindo sempre a mesma regra.

Veja esta sequência:

1
2
3
1
2
3
...

A regra aqui é: o bloco 1, 2, 3 se repete para sempre. Não existe uma soma nem uma multiplicação fixa entre um termo e o outro (de 1 para 2 aumenta 1, de 2 para 3 aumenta 1, mas de 3 para 1 diminui 2) — o que existe é um padrão que se repete. Para saber um termo, o jeito mais seguro é continuar escrevendo o bloco até chegar na posição que a questão pede.

A grande diferença: na sequência não recursiva que revisamos, dava pra substituir n numa fórmula T(n) e achar qualquer termo direto. Aqui não dá — não existe uma fórmula simples que calcule, por exemplo, o 50º termo dessa sequência sem eu ir contando o bloco 1, 2, 3 repetidamente. É por isso que, para descrever esse tipo de sequência com precisão, vamos usar outras ferramentas nas próximas partes da aula: o algoritmo e o fluxograma.
Agora é sua vez: nessa mesma sequência (1, 2, 3, 1, 2, 3...), qual é o 8º termo? Dica: escreva o bloco 1,2,3 quantas vezes forem precisas até contar 8 posições.
Dica para a prova: quando você vir uma sequência recursiva — seja com setas mostrando uma operação fixa (como "+5"), seja repetindo um bloco de números — ela está te dizendo como construir o próximo termo a partir do(s) anterior(es). Em alguns casos (como sequências com soma ou multiplicação constante) até existe uma fórmula T(n) que a gente consegue calcular; em outros, como este, não existe uma fórmula acessível pra gente agora, e o jeito mais seguro é continuar o padrão com calma.
Parte 4

Algoritmo: a receita de bolo da matemática

Vimos que, em algumas sequências recursivas, não existe uma fórmula T(n) simples pra usar — como no bloco 1, 2, 3 que se repete. Mas isso não é um problema: o algoritmo descreve qualquer sequência recursiva com precisão, tenha ela T(n) ou não.

Pense assim: um algoritmo é como uma receita de cozinha. Ela tem passos numerados, na ordem certa, e se você seguir exatamente esses passos, sempre chega ao mesmo resultado. Em matemática, um algoritmo é só isso: uma lista curta de instruções para construir uma sequência.

Vamos ver como isso funciona com a sequência 6, 11, 16, 21, 26... (essa, como vimos na revisão, até tem uma fórmula T(n) — mas o algoritmo também descreve ela perfeitamente, e vai ser essencial para os casos em que T(n) não existir):

  1. Passo 1. Escreva o valor 6.
  2. Passo 2. Some 5.
  3. Passo 3. Escreva o resultado.
  4. Passo 4. Retorne ao passo 2 (não ao passo 1!).

Repare que o passo 4 manda você voltar ao passo 2 — não ao passo 1. Isso é importante: se voltássemos ao passo 1, o algoritmo escreveria 6 de novo, depois somaria 5 e escreveria 11, depois voltaria ao passo 1 e escreveria 6 outra vez — a sequência ficaria alternando 6, 11, 6, 11, 6, 11... e nunca passaria do 11. O que realmente acontece é diferente: como o passo 4 manda voltar ao passo 2, o "some 5" sempre soma ao último resultado que você já escreveu, e não ao valor inicial. É por isso que a sequência cresce de verdade: 6, depois 11, depois 16, e assim por diante.

Para não se confundir, vale a pena registrar, a cada volta, qual é o "valor guardado" no momento:

O que fizValor guardado antesContaEscrevo

Passo 2 → 3 (1ª volta ao passo 2)66 + 511

Como resolver uma questão de algoritmo, sem se perder: pegue um papel e vá escrevendo o valor de cada passo, um debaixo do outro, exatamente na ordem que o algoritmo pede. Antes de somar de novo, confira: a que passo eu estou voltando? Se for "retorne ao passo 2" (ou outro passo do meio), o valor não reinicia — a conta continua a partir do último resultado escrito. Só reinicia se o algoritmo mandar voltar ao passo 1. Esse é o erro mais comum aqui, então vale conferir sempre.

Agora um exemplo um pouco diferente, para treinar a leitura com atenção:

  1. Passo 1. Comece com o número 2.
  2. Passo 2. Multiplique o termo anterior por 3.
  3. Passo 3. Some 1 ao resultado obtido.
  4. Passo 4. Escreva o novo termo.
  5. Passo 5. Retorne ao passo 2.

Fluxograma: o mesmo algoritmo, agora desenhado

Pense assim: se o algoritmo é a receita escrita em frases, o fluxograma é a mesma receita em forma de desenho com setas. Ele usa formas diferentes para dizer coisas diferentes: um formato oval para começar e terminar, um retângulo para uma ação, e um losango (formato de diamante) para uma pergunta de "sim ou não".

Parte 2 · Revisão

Relembrando: sequências não recursivas

Vocês já viram isso em aula: numa sequência não recursiva, existe uma fórmula — a expressão geradora T(n) — que calcula direto o valor de qualquer termo, sem precisar passar pelos termos anteriores. Vamos relembrar rapidinho antes de seguir.

Pense assim: T(n) é uma "máquina de termos". Você entra com a posição que quer (o valor de n: 1º, 2º, 3º...) e ela devolve o valor do termo naquela posição, sem precisar saber nenhum termo anterior. É só substituir o n pelo número da posição e fazer a conta.

Exemplo: uma sequência com expressão geradora T(n) = 5n + 1. Vamos testar, substituindo n por cada posição:

nSubstituindoT(n)
15 · 1 + 16
25 · 2 + 111
35 · 3 + 116

Repare: para achar o 3º termo, eu não precisei saber o 1º nem o 2º — troquei o n por 3 e resolvi a conta direto. É essa a marca registrada de uma sequência não recursiva.

Passo a passo para resolver qualquer T(n):
1. Veja qual termo a questão está pedindo (esse número vira o "n").
2. Troque a letra n pelo número, em todo lugar que ela aparecer.
3. Resolva a conta seguindo a ordem: primeiro multiplicação, depois soma.

Vamos praticar com outra fórmula: T(n) = 4n − 2.

Qual é o 3º termo dessa sequência? (substitua n por 3)
Guarde essa ideia: quando existe uma fórmula T(n) que resolve tudo de uma vez, a sequência é não recursiva. Já vamos ver um tipo de sequência bem diferente, em que isso não é possível.

📓 Resumo da aula

Existem dois tipos de sequência. Numa sequência não recursiva, existe uma fórmula chamada expressão geradora, escrita como T(n), que calcula diretamente o valor de qualquer termo, sem precisar passar pelos termos anteriores. Para usá-la, substituímos a letra n pela posição do termo que queremos descobrir e resolvemos a conta, respeitando a ordem: primeiro multiplicação, depois soma ou subtração. Por exemplo, se T(n) = 5n + 1, o 3º termo é 5 vezes 3, mais 1, ou seja, 16.

Já numa sequência recursiva, cada termo novo é construído a partir do termo anterior, seguindo sempre a mesma regra. Em alguns casos (como sequências em que somamos ou multiplicamos sempre o mesmo valor) até é possível encontrar uma fórmula T(n). Mas em outros casos — como o bloco 1, 2, 3, 1, 2, 3... que se repete para sempre — não existe uma fórmula T(n) simples, e a única forma segura de achar um termo é continuar o padrão a partir do(s) termo(s) anterior(es).

Como não temos uma fórmula direta para as sequências recursivas, aprendemos duas outras formas de descrevê-las com precisão. A primeira é um algoritmo, que é uma lista de passos numerados, parecida com uma receita de cozinha, incluindo um passo que manda "retornar" a um passo anterior para repetir o processo quantas vezes forem necessárias. É importante prestar atenção a qual passo ele manda voltar: se for um passo do meio (como "retorne ao passo 2"), o valor não reinicia — a conta continua a partir do último resultado escrito; mas se o retorno for ao passo 1, o valor volta ao início, e a sequência pode até repetir os mesmos números. A segunda é um fluxograma, que é a mesma receita desenhada com setas, retângulos para ações e losangos para perguntas do tipo sim ou não, que decidem se o processo repete ou termina.

Também estudamos sequências recursivas formadas por figuras, como padrões de palitos de fósforo, em que a estratégia é descobrir quanto a figura cresce de uma etapa para a outra e continuar essa soma até chegar na figura pedida. Por fim, conhecemos a sequência de Fibonacci (1, 1, 2, 3, 5, 8, 13...), uma sequência recursiva famosa em que cada termo é a soma dos dois termos anteriores — outro exemplo em que não existe uma fórmula T(n) simples.

Ideia principal para guardar: nem toda sequência tem uma fórmula T(n) fácil de achar. Quando ela existir, ótimo — use-a. Quando não existir (ou parecer complicada demais), descreva a sequência com setas, com um algoritmo ou com um fluxograma, dependendo do que a questão está pedindo.
