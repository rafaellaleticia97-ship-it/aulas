Parte 1 · Ponto de partida

Vamos pensar juntos

Responda essa pergunta antes de qualquer explicação. Você provavelmente já sabe fazer isso de cabeça.

Quais dois números, multiplicados, dão 6, e somados, dão 5?

Esses dois números são exatamente a chave para resolver equações do 2º grau por fatoração — e é exatamente o que vamos revisar hoje.

Parte 2 · Revisão

Fatoração de trinômios

Antes de revisar a fatoração, vale lembrar dois nomes que vamos usar bastante hoje: binômio e trinômio.

Binômio Uma expressão algébrica com dois termos, separados por + ou −. (x + 2)
Trinômio Uma expressão algébrica com três termos. x² + 5x + 6

Fatorar um trinômio é justamente reescrevê-lo como um produto de dois binômios — ou seja, trocar três termos somados por duas expressões multiplicadas, que dão o mesmo resultado.

Você já viu isso antes. Para um trinômio no formato x² + bx + c, o segredo é achar dois números que:

multiplicados
= c
somados
= b

Exemplo rápido: em x² + 5x + 6, procuramos dois números que multiplicados dão 6 e somados dão 5. São o 2 e o 3. Por isso escrevemos o trinômio como produto de dois binômios:

x² + 5x + 6  =  (x + 2)(x + 3)

Parte 3 · Conceito novo

O que é uma equação do 2º grau

Uma equação do 2º grau é qualquer equação que pode ser escrita nesta forma:

a·x² + b·x + c = 0

com a, b e c números reais e a diferente de zero (se a fosse zero, o x² desapareceria e não seria mais do 2º grau).

As raízes são os valores de x que tornam essa igualdade verdadeira.

💡 Pense assim

Se você desenhar o gráfico de y = ax² + bx + c, vai ver uma curva (parábola). As raízes são exatamente os pontos onde essa curva toca o eixo x — porque é ali que y vale 0.

Exemplo: y = x² − 3. Os pontos em coral são as raízes (onde a curva toca o eixo x) e o ponto em roxo é o vértice (V).

Parte 4 · Por fatoração

Resolvendo por fatoração

Quando a equação é fatorável, resolvê-la fica simples: se um produto de dois fatores dá zero, pelo menos um dos fatores tem que ser zero.

💡 Pense assim

Se você multiplica dois números e o resultado é zero, um deles obrigatoriamente é zero — não existe outro jeito. É essa ideia que usamos aqui.

Exemplo passo a passo

Vamos resolver x² − 7x + 12 = 0.

PassoO que fazemos
1Procurar dois números que multiplicados dão 12 e somados dão −7 → são −3 e −4
2Fatorar: (x − 3)(x − 4) = 0
3Cada fator pode ser zero: x − 3 = 0 ou x − 4 = 0
4Resolver cada um: x = 3 ou x = 4
⚠️ Dica

Sempre confira as duas condições ao mesmo tempo: o produto E a soma. Um número pode "bater" no produto mas não na soma — e aí não é a fatoração certa.

Agora é sua vez: resolva x² − 6x + 8 = 0 por fatoração.

Parte 5 · Fórmula de Bhaskara

Quando a fatoração não é óbvia

Nem toda equação é fácil de fatorar de cabeça. Para esses casos, existe uma fórmula que sempre funciona:

x =
−b ± √b² − 4ac
2a
💡 Pense assim

A fórmula de Bhaskara é como uma receita: você sempre identifica a, b e c, calcula Δ, e depois substitui tudo. Ela funciona para qualquer equação do 2º grau, mesmo as que não dá para fatorar de cabeça.

Exemplo passo a passo

Vamos resolver 3x² − 5x + 2 = 0.

PassoCálculo
1. Identificara = 3, b = −5, c = 2
2. Calcular ΔΔ = (−5)² − 4·3·2 = 25 − 24 = 1
3. Aplicar a fórmulax = (5 ± √1) / 6 = (5 ± 1) / 6
4. Duas raízesx = 6/6 = 1  ou  x = 4/6 = 1/3
⚠️ Dica

O erro mais comum é esquecer o sinal de b. Se b = −5, então −b = 5, não −5. Escreva esse sinal com calma antes de substituir. E não esqueça o ± : ele te dá duas respostas, não uma só.

Agora é sua vez: resolva x² − 3x − 4 = 0 usando Bhaskara.

Parte 6 · Procedimento

O caminho completo, passo a passo

Passo 1. Identifique a, b e c na equação ax² + bx + c = 0.
Passo 2. Calcule Δ = b² − 4ac.
Passo 3. Verifique o sinal de Δ.
Passo 4. Se Δ ≥ 0, aplique x = (−b ± √Δ) / 2a. Se Δ < 0, não há raízes reais.
⚠️ Dica

Δ = 0 não significa que não há solução — significa que existe uma raiz real (repetida). Só Δ < 0 é que não tem raiz real.

Parte 7 · Discriminante

O que Δ conta sobre a equação

Antes mesmo de terminar a conta, o valor de Δ já revela quantas raízes reais a equação tem — e o que acontece com a parábola no gráfico.

Sinal de ΔRaízes reaisParábola e o eixo x
Δ > 0duas raízes diferentescruza o eixo x em 2 pontos
Δ = 0uma raiz (dupla)toca o eixo x em 1 ponto
Δ < 0nenhuma raiz realnão toca o eixo x
💡 Pense assim

Calcular Δ antes de resolver tudo é como espiar o resultado da corrida antes dela terminar: você já sabe se vai ter 2 raízes, 1 raiz ou nenhuma — sem gastar tempo com a fórmula toda.

Parte 9 · Resumo

Para o caderno

Uma equação do 2º grau tem a forma ax² + bx + c = 0, com a diferente de zero, e suas raízes são os valores de x que tornam essa igualdade verdadeira — no gráfico, são os pontos onde a parábola toca o eixo x. Quando a equação é fatorável, resolvemos procurando dois números cujo produto é c e cuja soma é b, escrevendo o trinômio como o produto de dois binômios, (x + p)(x + q) = 0, e igualando cada fator a zero. Quando a fatoração não é óbvia, usamos a fórmula de Bhaskara: calculamos primeiro o discriminante Δ = b² − 4ac e depois aplicamos x = (−b ± √Δ) / 2a. O próprio Δ já conta boa parte da história antes de terminarmos a conta: se Δ for maior que zero, a equação tem duas raízes reais diferentes; se Δ for igual a zero, tem uma raiz real repetida; e se Δ for menor que zero, não existe raiz real. Com esses três caminhos — fatoração, discriminante e fórmula de Bhaskara — você já está pronto para começar a estudar função do 2º grau, porque as raízes que aprendemos a encontrar aqui são exatamente os pontos onde o gráfico dessas funções cruza o eixo x.
