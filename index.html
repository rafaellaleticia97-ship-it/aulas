Soma dos ângulos internos do triângulo

Em qualquer triângulo, os três ângulos internos sempre somam 180°. Isso nunca muda — nem no triângulo mais estranho do mundo!

∠A + ∠B + ∠C = 180°
📌 Isso vale para qualquer triângulo — grande, pequeno, reto, obtuso, isósceles. Sempre 180°, sem exceção.
💡
Como usar esse conteúdo

Nas questões sobre triângulos, você geralmente recebe 2 ângulos e precisa encontrar o terceiro. A estratégia é sempre a mesma:

1
Some os ângulos que você já temEx: 73° + 49° = 122°
2
Subtraia de 180°180° − 122° = 58°
3
Essa é a respostaO terceiro ângulo mede 58°

E se os ângulos tiverem x?

Some tudo e iguale a 180°. Exemplo: (x+10)° + (2x+20)° + (3x−30)° = 180°

1
Junte os termos com xx + 2x + 3x = 6x
2
Junte os números10 + 20 − 30 = 0
3
Resolva a equação6x = 180° → x = 30°
⚠️Nunca esqueça: o resultado de x tem que gerar ângulos positivos! Se der negativo, tem algo errado na conta.

Soma dos ângulos internos de polígonos

Qualquer polígono pode ser cortado em triângulos. Cada triângulo soma 180°. Por isso temos a fórmula:

Fórmula geralS = (n − 2) × 180°

onde n é o número de lados do polígono.

🧩Memorize assim: tire 2 do número de lados, depois multiplique por 180. Simples!
📋

🌟 A questão pode dar a soma e pedir o número de lados. Faça ao contrário: S ÷ 180 + 2 = n
🔄
Quando a questão dá a soma e pede os lados

Exemplo: Soma = 1.080°. Quantos lados?

1
Monte a equação(n − 2) × 180 = 1080
2
Divida os dois lados por 180n − 2 = 1080 ÷ 180 = 6
3
Some 2n = 6 + 2 = 8 lados → octógono

Como resolver as questões

Tipo 1 — Ângulos com expressões (alternos ou correspondentes):

1
Identifique que são iguaisEx: alterno interno → (4x−10)° = (2x+30)°
2
Monte a equação e resolva4x − 10 = 2x + 30 → 2x = 40 → x = 20

Tipo 2 — Co-internos (somam 180°):

1
Identifique que somam 180°Ex: um ângulo é 72°
2
Subtraia de 180°180° − 72° = 108°

Os 3 Produtos Notáveis

São fórmulas essenciais que precisam estar na ponta da língua!

Quadrado da soma
(a+b)² =
a²+2ab+b²
Quadrado da diferença
(a−b)² =
a²−2ab+b²
Produto da soma pela diferença
(a+b)(a−b) =
a²−b²
🧩Atenção ao termo do meio! No quadrado da soma é +2ab, na diferença é −2ab. Só muda o sinal do meio!
🔍
Passo a passo — Quadrado da soma

Exemplo: (3x + 2)²

1
Identifique a e ba = 3x    b = 2
2
Calcule a²(3x)² = 9x²
3
Calcule 2ab2 × 3x × 2 = 12x
4
Calcule b²2² = 4
5
Monte o resultado(3x+2)² = 9x² + 12x + 4
( 3x + 2 )² = 9x² + 12x + 4
🔍
Área sombreada com dois quadrados

Quando temos dois quadrados e queremos a área sombreada (grande menos pequeno), usamos produtos notáveis.

Exemplo: Quadrado grande de lado (x+4), quadrado pequeno de lado (x−1) retirado do canto inferior direito.

1
Área grande − Área pequena(x+4)² − (x−1)²
2
Expanda cada quadrado(x²+8x+16) − (x²−2x+1)
3
Distribua o sinal de subtraçãox²+8x+16 − x²+2x−1
4
Simplifique10x + 15
⚠️Cuidado ao distribuir o sinal de "−" no segundo parêntese! Todo sinal dentro inverte.

O que é fatoração?

Fatorar é reescrever uma expressão como um produto de fatores. É o caminho inverso de expandir.

📌 Expandir: (x+3)(x+4) → x²+7x+12
📌 Fatorar: x²+7x+12 → (x+3)(x+4)
🧩A fatoração transforma a equação num produto = 0, e aí fica fácil achar as raízes!
1️⃣
Diferença de quadrados: a² − b²
a² − b² = (a + b) · (a − b)

Exemplo: x² − 64 = x² − 8² = (x+8)(x−8)

1
Identifique a raiz de cada termo√x² = x    √64 = 8
2
Monte os fatores(x + 8) · (x − 8)
3
Aplique produto zero para equação = 0x+8=0 → x=−8    x−8=0 → x=8
S = { −8 ; 8 }
2️⃣
Fatoração do trinômio: x² + bx + c

Procure dois números que multiplicam para dar c e somam para dar b.

1
Liste pares com produto = cPara x²+2x−15: c = −15 → pares: 1×(−15), 3×(−5), 5×(−3)...
2
Qual par soma b?b = +2 → 5 e (−3): 5+(−3)=2 ✓ e 5×(−3)=−15 ✓
3
Monte os fatores(x + 5)(x − 3) = 0
4
Produto zerox = −5 ou x = 3
S = { −5 ; 3 }
⚠️Se a equação tiver coeficiente em x² (como 3x²), divida tudo pelo coeficiente primeiro antes de fatorar!
