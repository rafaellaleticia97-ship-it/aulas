Polinômios

Para começar

Letras no lugar de números

Um caderno custa um preço que você ainda não sabe. Vamos chamar esse preço de x.

Quanto custam 4 cadernos? Custam 4 vezes o preço de um, ou seja, 4 · x, que escrevemos 4x.

Você acabou de escrever uma expressão algébrica: uma expressão com números e letras. As letras são chamadas de variáveis, porque representam números que podem variar.

Parte 1

O que é um monômio

Um monômio é um número multiplicado por letras, e os expoentes das letras são números naturais (0, 1, 2, 3, …). Ele é uma "peça" só, sem soma nem subtração no meio.

Todo monômio tem duas partes. O número é o coeficiente. As letras, com seus expoentes, formam a parte literal.

−6
coeficiente
x²y
parte literal
Pense assim Em "3 maçãs", o número 3 diz quantas e a palavra "maçãs" diz o quê. No monômio 3x² é igual: o coeficiente 3 diz quantas vezes, e a parte literal x² diz o que está sendo contado.
Parte 1

O grau do monômio

O grau de um monômio é a soma dos expoentes de todas as letras dele.

Em 3x²y, o x tem expoente 2 e o y tem expoente 1. Então o grau é 2 + 1 = 3.

Dica: o número que "não aparece" Quando uma letra aparece sem expoente, o expoente dela é 1: y = y¹. Quando não aparece número na frente, o coeficiente é 1 (ou −1, se tiver o sinal de menos): −y⁴ = −1 · y⁴. E um número sozinho, como 12, tem grau 0, porque não tem nenhuma letra (é como se fosse 12x⁰, e x⁰ = 1).
Parte 2

Juntando monômios: o polinômio

Um polinômio é uma soma de monômios. Cada monômio dentro dele se chama termo.

Em x² + 4x − 5 há três termos: x², 4x e −5. Repare que o sinal de menos fica junto com o termo que vem depois dele.

O nome muda conforme a quantidade de termos:

1 termo8k²monômio
2 termos3a − 1binômio
3 termosx² + 4x − 5trinômio
4 ou mais2y³ − y² + y + 9polinômio
Pense assim Os prefixos são os mesmos de palavras que você já conhece: mono = um (monociclo), bi = dois (bicicleta), tri = três (triciclo), poli = muitos.

Parte 2

Quando NÃO é polinômio

Para ser polinômio, toda letra precisa ter expoente natural. Por isso, a expressão deixa de ser polinômio quando uma variável tem expoente negativo ou aparece no denominador (embaixo da fração).

✗ Não é polinômio4x⁻² + 1 (expoente −2)
5/y + 3 (letra embaixo)
✓ É polinômiox/2 − 7 (o número 2 é que está embaixo)
√2 · y (a raiz está no número)
Dica: olhe só para as letras O que decide é a letra, não o número. Fração, raiz ou vírgula no coeficiente não atrapalham nada: x/2 é o mesmo que ½ · x, que é um monômio comum. O problema só aparece quando a letra vai para o denominador ou ganha expoente negativo.
Parte 2

Termos semelhantes

Dois termos são semelhantes quando têm exatamente a mesma parte literal: as mesmas letras, com os mesmos expoentes. O coeficiente pode ser diferente.

✓ Semelhantes3ab² e −ab²
(os dois têm ab²)
✗ Não semelhantes4x² e 4x
(x² é diferente de x)

Exemplo

Em 5p²q − 2pq² + p²q, os termos 5p²q e p²q são semelhantes. O termo −2pq² não é semelhante a eles, porque nele o expoente 2 está no q, e não no p.

Dica: coeficiente igual não basta Um erro comum é achar que 4x² e 4x são semelhantes porque os dois têm o número 4. O coeficiente não importa aqui. Compare só a parte literal, letra por letra e expoente por expoente.
Parte 3

Somando polinômios

Só podemos somar ou subtrair termos semelhantes. Fazemos a conta com os coeficientes e mantemos a parte literal igual.

7x² − 2x² = 5x²

Pense assim 3 maçãs + 2 maçãs = 5 maçãs. Mas 3 maçãs + 2 laranjas não vira 5 "maçaranjas": fica do jeito que está. Com polinômios é igual: 3x + 2x = 5x, mas 3x² + 2x não junta, porque x² e x são "frutas" diferentes.
Parte 3

As peças dos modelos algébricos

Podemos representar cada termo com peças. A área de cada peça é o valor que ela representa. As peças listradas são negativas.

Uma peça positiva e uma negativa do mesmo tipo se anulam, porque juntas valem zero: x + (−x) = 0.

Parte 3

Exemplo: somando com as peças

(x² + 2x − 1) + (x² − x + 3)

x² + 2x − 1
x² − x + 3

Parte 3

A mesma conta, sem as peças

As peças ajudam a entender, mas a conta escrita segue a mesma ideia: juntamos cada grupo de termos semelhantes.

(x² + 2x − 1) + (x² − x + 3)
= x² + 2x − 1 + x² − x + 3tiramos os parênteses
= (x² + x²) + (2x − x) + (−1 + 3)agrupamos os semelhantes
= 2x² + x + 2operamos os coeficientes
Dica: o sinal anda com o termo Na hora de agrupar, leve o sinal junto: em 2x − x, o termo é −x, que vale −1x. Por isso 2x − x = 1x = x, e não 2x.
Parte 4

O sinal antes dos parênteses

Antes de juntar os termos, precisamos tirar os parênteses. O que acontece depende do sinal que está na frente deles.

Sinal + na frente

Tiramos os parênteses e mantemos todos os sinais.

+(2x − 5) = 2x − 5

Sinal − na frente

Tiramos os parênteses e trocamos todos os sinais de dentro.

−(2x − 5) = −2x + 5

Pense assim O sinal de menos na frente dos parênteses é como dizer "o contrário de tudo isto". O contrário de ganhar 2x é perder 2x, e o contrário de perder 5 é ganhar 5. Por isso cada sinal de dentro vira o seu oposto.
Parte 4

Exemplo: subtraindo polinômios

(4x² + 3x − 5) − (x² − 2x − 6)

(4x² + 3x − 5) − (x² − 2x − 6)
= 4x² + 3x − 5 − x² + 2x + 6trocamos os 3 sinais do 2º parêntese
= (4x² − x²) + (3x + 2x) + (−5 + 6)agrupamos os semelhantes
= 3x² + 5x + 1operamos os coeficientes
Dica: o erro mais comum desta aula Muita gente troca só o sinal do primeiro termo e esquece os outros. Em −(x² − 2x − 6) há três termos dentro, então são três sinais para trocar: −x² + 2x + 6. Conte os termos antes de trocar e confira se trocou todos.
Parte 4

Mais um detalhe: potência de um produto

Quando um produto inteiro está elevado a um expoente, o expoente vale para cada fator de dentro: para o número e para a letra.

(3x)² = 3² · x² = 9x²

Dica: não esqueça o número É comum elevar só a letra e escrever (3x)² = 3x². Mas (3x)² quer dizer 3x · 3x, e 3 · 3 = 9. O resultado certo é 9x².
