Fácil Triângulos · ENEM adaptada
Em um triângulo, dois ângulos medem 45° e 75°. Qual é a medida do terceiro ângulo?

📝 Passo a passo

Passo 1 — Lembre a regra: a soma dos ângulos internos de qualquer triângulo é 180°.
Passo 2 — Você já conhece dois ângulos: 45° e 75°. Some eles: 45° + 75° = 120°.
Passo 3 — Subtraia de 180°: 180° − 120° = 60°.
✅ Resposta correta: C) 60°
2
Fácil Quadrilátero · ENEM adaptada
Um quadrilátero tem três ângulos que medem 80°, 100° e 90°. Qual é a medida do quarto ângulo?

📝 Passo a passo

Passo 1 — Quadrilátero tem 4 lados → use a fórmula: S = (4 − 2) · 180° = 360°.
Passo 2 — Some os três ângulos conhecidos: 80° + 100° + 90° = 270°.
Passo 3 — Calcule o quarto: 360° − 270° = 90°.
✅ Resposta correta: C) 90°
3
Fácil Polígonos · Vestibular adaptada
Qual é a soma dos ângulos internos de um pentágono (figura de 5 lados)?

📝 Passo a passo

Passo 1 — A fórmula é: S = (n − 2) · 180°. Aqui, n = 5.
Passo 2 — Substitua: S = (5 − 2) · 180° = 3 · 180°.
Passo 3 — Calcule: 3 × 180° = 540°.
✅ Resposta correta: C) 540°

Fácil Ângulos opostos · ENEM adaptada
Duas retas se cruzam. Um dos ângulos formados mede 130°. Qual é a medida do ângulo oposto a ele pelo vértice?

📝 Passo a passo

Regra — Ângulos opostos pelo vértice são sempre iguais.
Aplicando — O ângulo mede 130°, então o oposto também mede 130°.
✅ Resposta correta: B) 130°

Médio Polígono regular · Vestibular adaptada
Um hexágono regular (6 lados iguais e 6 ângulos iguais). Qual é a medida de cada ângulo interno?

📝 Passo a passo

Passo 1 — Calcule a soma total: S = (6 − 2) · 180° = 4 · 180° = 720°.
Passo 2 — Como é regular, todos os ângulos são iguais. Divida pela quantidade de ângulos: 720° ÷ 6 = 120°.
✅ Resposta correta: C) 120°

Médio Paralelismo · ENEM adaptada
Duas retas paralelas são cortadas por uma transversal. Um dos ângulos correspondentes mede 65°. Qual é a medida do ângulo correspondente na outra reta?

📝 Passo a passo

Regra — Quando retas são paralelas, os ângulos correspondentes (no mesmo "lugar" em relação à transversal) são sempre iguais.
Aplicando — O ângulo mede 65°, então o correspondente também mede 65°.
✅ Resposta correta: D) 65°

Médio Ângulos suplementares · Vestibular adaptada
Dois ângulos são suplementares. Um deles mede 3x e o outro mede x + 20°. Qual é o valor de x?

📝 Passo a passo

Passo 1 — Suplementares somam 180°. Então: 3x + (x + 20°) = 180°.
Passo 2 — Some os termos com x: 4x + 20° = 180°.
Passo 3 — Isole o x: 4x = 180° − 20° = 160°.
Passo 4 — Divida: x = 160° ÷ 4 = 40°.
✅ Resposta correta: C) 40°

Médio Polígono · ENEM adaptada
Um polígono convexo tem a soma dos ângulos internos igual a 1080°. Quantos lados tem esse polígono?

📝 Passo a passo

Passo 1 — Use a fórmula ao contrário: S = (n − 2) · 180°. Sabemos que S = 1080°.
Passo 2 — Escreva a equação: (n − 2) · 180° = 1080°.
Passo 3 — Divida os dois lados por 180°: n − 2 = 1080° ÷ 180° = 6.
Passo 4 — Some 2 nos dois lados: n = 6 + 2 = 8.
✅ Resposta correta: C) 8 lados (octágono)
