Ângulos em Polígonos e Retas

Resumo + Quiz estilo ENEM e Vestibular

△ 1. Ângulos em Triângulos
  • 1Todo triângulo tem 3 ângulos internos: â, b̂ e ĉ.
  • 2A soma desses 3 ângulos é sempre 180° — não importa o formato do triângulo!
  • 3Se você conhece dois ângulos, subtraia de 180° para encontrar o terceiro.
â + b̂ + ĉ = 180°
Exemplo: ângulos de 60° e 70° → terceiro = 180° − 60° − 70° = 50°
⬠ 2. Ângulos em Polígonos
  • 1Polígono = figura fechada com lados retos (triângulo, quadrado, pentágono…).
  • 2Divida o polígono em triângulos puxando diagonais de um vértice.
  • 3Conte os triângulos: sempre sai n − 2 triângulos.
  • 4Multiplique pelo 180° de cada triângulo e você tem a soma dos ângulos!
S = (n − 2) · 180°
n = número de lados. Subtraia 2 e multiplique por 180°.

↗ 3. Ângulos e Retas
Opostos pelo Vértice
Quando 2 retas se cruzam, os ângulos opostos são sempre iguais: â = â
Ângulos Suplementares
Dois ângulos sobre uma reta somam 180°. x + y = 180°
Correspondentes
Paralelas + transversal: ângulos no mesmo lado e mesma posição são iguais.
Alternos Internos
Paralelas + transversal: ângulos em lados opostos, entre as paralelas, são iguais.
r ∥ s + transversal t → correspondentes iguais e alternos internos iguais
O símbolo ∥ significa "paralelas". Quando ver duas retas paralelas cortadas por uma terceira, os ângulos correspondentes e alternos internos são iguais!
⚡ Resumão — Regras para a Prova
  • ★Triângulo → soma dos ângulos internos = 180°
  • ★Qualquer polígono → S = (n − 2) · 180°
  • ★Quadrilátero → soma sempre = 360°
  • ★Polígono regular → cada ângulo = S ÷ n
  • ★Ângulos opostos pelo vértice → sempre iguais
  • ★Ângulos suplementares → somam 180°
  • ★Paralelas + transversal → correspondentes e alternos internos iguais

Passo 3 — Quarto: 360° − 270° = 90°.
✅ Resposta correta: C) 90°

Um hexágono regular tem 6 lados e 6 ângulos todos iguais. Qual é a medida de cada ângulo interno?

📝 Passo a passo

Passo 1 — Soma total: S = (6−2)·180° = 4·180° = 720°.
Passo 2 — Como é regular, divide pelo número de ângulos: 720° ÷ 6 = 120°.
✅ Resposta correta: C) 120°

MédioSuplementares · Vestibular adaptada
Dois ângulos são suplementares. Um mede 3x e o outro mede x + 20°. Qual é o valor de x?

📝 Passo a passo

Passo 1 — Suplementares somam 180°: 3x + (x + 20°) = 180°.
Passo 2 — Junte os x: 4x + 20° = 180°.
Passo 3 — Isole: 4x = 160° → x = 40°.
✅ Resposta correta: C) 40°

A soma dos ângulos internos de um polígono convexo é 1080°. Quantos lados ele tem?

📝 Passo a passo

Passo 1 — Use a fórmula ao contrário: (n−2)·180° = 1080°.
Passo 2 — Divida: n−2 = 1080÷180 = 6.
Passo 3 — Some 2: n = 6+2 = 8 lados (octágono).
