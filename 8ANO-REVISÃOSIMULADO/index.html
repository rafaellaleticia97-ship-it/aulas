Expressão Algébrica

É uma conta que tem letras (variáveis) e números juntos. Exemplo: d = 5 + 20,5 · t

🔢

Valor Numérico

Quando você substitui a letra por um número e resolve a conta. Exemplo: se t = 2 → d = 5 + 20,5 · 2 = 46

03
📈

Função do 1º Grau

Escrita como y = ax + b. O "a" indica a velocidade de crescimento e o "b" é o ponto de partida.

04
📐

Gráfico = Reta

O gráfico de toda função do 1º grau é uma linha reta no plano cartesiano. Dois pontos já bastam para traçá-la!

Fórmula Principal
y = a · x + b
a = coeficiente angular (inclinação)  |  b = coeficiente linear (onde cruza o eixo y)
💡 Dicas Diretas
  • 🥇 Ordem das operações: Multiplicação e divisão sempre antes de soma e subtração. Em 5 + 20,5 · 3, primeiro faço 20,5 × 3 = 61,5, depois 5 + 61,5 = 66,5.
  • ✏️ Substituir variável: Troque a letra pelo número e resolva passo a passo, sem pular etapas.
  • 📌 Para traçar a reta: Escolha 2 valores de x qualquer, calcule o y para cada um, marque os dois pontos e ligue com uma reta.
  • ⚠️ Cuidado com divisão por zero: Se substituir um número fizer o denominador virar zero, esse valor não pode ser usado.
  • 🔄 Equação linear: Você pode somar, subtrair, multiplicar ou dividir os dois lados da equação pelo mesmo número para isolar a variável.
